# Security policy

CompatAir MCP is a public, read-only endpoint. Do not report vulnerabilities through a public GitHub issue.

Report a vulnerability privately to `contact@l0g.fr` and include the affected endpoint or contract version, impact and minimal reproduction details. The current web policy is published at https://compatair.fr/securite/ and the machine-readable contact is https://compatair.fr/.well-known/security.txt.

Never include credentials, personal data, active affiliate tokens or destructive payloads in a report.

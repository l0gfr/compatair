Trouver une référence dans un catalogue fabricant permet de documenter ses caractéristiques. Cela ne démontre pas qu’elle est disponible aujourd’hui chez un vendeur, ni que toutes les versions évoquées dans une ancienne brochure sont encore proposées. Cette distinction évite de transformer une bonne source technique en promesse commerciale.

| Référence exacte | Données pneumatiques publiées | Autres repères |
| --- | --- | --- |
| [CY9RAM-WP](/outils-pneumatiques/fiam-cy9ram-wp/) (116514109) | 600 L/min ; 6,3 bar | Vitesse à vide : 700 tr/min ; Masse publiée : 1.67 kg |
| [345-3008-31-HM](/outils-pneumatiques/deprag-345-3008-31-hm/) (500100A) | 100 L/min ; 6,3 bar | Couple minimal : 1 Ncm ; Couple maximal : 15 Ncm ; Vitesse à vide : 1700 tr/min |

Sources fabricant consultées le 26 septembre 2026 : [Fiam CY9RAM-WP](https://www.fiamgroup.com/wp-content/uploads/2019/11/en-24.pdf#page=4), [DEPRAG 345-3008-31-HM](https://www.deprag.com/fileadmin/bilder_content/emedia/broschueren_pics/emedia_schraubtechnik/D3125/D3125en.pdf#page=3).

## Les trois documents à rapprocher

| Document | Ce qu’il permet de contrôler |
| --- | --- |
| Fiche ou brochure fabricant | Caractéristiques et référence du modèle documenté |
| Notice de la version livrée | Installation, utilisation et prescriptions applicables |
| Offre datée du vendeur | Configuration vendue, disponibilité annoncée et conditions commerciales |

Pour CY9RAM-WP, le code 116514109 relie l’outil à sa ligne Fiam. Pour la microvisseuse DEPRAG, le code 500100A permet notamment de préserver l’unité Ncm de la plage de couple. Ces identifiants doivent se retrouver dans l’offre, et pas seulement dans une page consultée en amont.

## Traiter une proposition de remplacement

Si la référence n’est plus disponible, demandez le code exact du produit proposé et sa propre documentation. Ne transférez pas automatiquement le débit, le couple ou les accessoires de l’ancien modèle au nouveau. La comparaison doit être refaite champ par champ pour les critères qui conditionnent le poste.

Une offre « équivalente » peut être pertinente, mais l’équivalence reste à démontrer pour l’application. Le [guide de lecture du code fabricant](/guides/compresseur-reference-erp-nom-commercial/) présente ce problème d’identité sur les compresseurs ; le même contrôle documentaire est utile aux outils.

CompatAir peut donc publier une fiche technique tout en indiquant qu’aucun vendeur n’est vérifié. Cette absence de lien marchand est préférable à une disponibilité inventée. Pour acheter, partez des caractéristiques traçables puis obtenez une offre actuelle correspondant à la bonne référence.

La pression de référence est documentée dans [Fiam, brochure technique en-24, page PDF 4](https://www.fiamgroup.com/wp-content/uploads/2019/11/en-24.pdf#page=4).

Les [ATP1043EO-5S et TH](/guides/atp1043eo-sortie-spline-carre-retenue/) montrent pourquoi la sortie, la retenue et une contradiction de gâchette doivent être résolues dans le dossier de commande.

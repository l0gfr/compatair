Une annonce « compresseur 230 V » ne suffit pas pour savoir s’il convient à une alimentation monophasée. Le nombre de phases est une caractéristique distincte. Le catalogue industriel contient aussi des versions 230 V triphasées.

Le [tableau officiel des variantes ABAC SPINN](https://shop.abacaircompressors.com/en-INT/products/4152054944/spinn22-8-40050k-e-ce), consulté le 26 septembre 2026, décrit notamment la référence **4152022526**, **SPINN 5.5X 8 230/50 FM**. Dans les caractéristiques de cette variante, les champs indiquent :

| Champ fabricant | Valeur |
| --- | --- |
| Supply voltage | 230 V |
| Frequency | 50 Hz |
| Number of phases | 3 |
| Motor | 5,5 kW |
| FAD capacity | 846 L/min |
| Max Working Pressure | 8 bar |
| Vessel size | 0 L |

Les trois premières lignes doivent rester ensemble. La présence de 230 V dans le nom n’autorise pas à remplacer « trois phases » par « monophasé ».

## Préparer la vérification du site

Communiquez au professionnel chargé de l’installation la référence exacte et la documentation électrique du fabricant. Il pourra vérifier l’adéquation avec l’alimentation disponible, les protections et les prescriptions de raccordement. La fiche commerciale ne suffit pas pour dimensionner ces éléments.

Ce guide ne propose ni changement de couplage ni montage de condensateur ni ajout d’un variateur pour rendre la machine compatible avec une autre alimentation. Une possibilité de conversion doit être explicitement validée pour le produit complet, y compris ses auxiliaires et sa commande, et pas seulement imaginée à partir du moteur.

## Contrôler aussi la variante sélectionnée en ligne

Un site de fabricant peut afficher une page de famille regroupant plusieurs dizaines de variantes. La référence visible dans l’adresse de la page n’est alors pas nécessairement celle de la ligne consultée. Vérifiez le code sélectionné dans le tableau et sur le devis.

Pour cet exemple, le code 4152022526 identifie la ligne 230 V, 50 Hz, trois phases. La [fiche CompatAir correspondante](/compresseurs/abac-spinn-5-5x-8-230-50-fm/) conserve cette identité. Une autre ligne de la même gamme peut avoir une autre tension, un réservoir ou un sécheur ; les valeurs ne doivent pas être transférées automatiquement.

Le [guide des versions 50 et 60 Hz](/guides/compresseur-50hz-60hz-versions/) traite la vérification suivante. Ces détails peuvent paraître secondaires pendant une recherche de prix, mais ils déterminent si les offres portent réellement sur le même équipement.

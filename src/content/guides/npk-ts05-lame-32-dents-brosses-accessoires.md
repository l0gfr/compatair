**La lame TS-05 de 32 dents porte le code 24906210.** Le tableau NPK voisin présente aussi des lames de 24 dents pour d’autres modèles. Lire la page sans suivre ses lignes peut conduire à commander un consommable qui n’est pas documenté pour la TS-05.

## Suivre la ligne de modèle, puis la colonne

La [page scie-lime du catalogue NPK avril 2026, page PDF 14](https://www.npk-en.com/app/download/10804376570/NPK_air_tool_catologue_apr2026.pdf?t=1777353985#page=14) présente la TS-05, code outil 15421, avec une lame de 32 dents incluse. Dans le tableau des lames, sa case « 24 dents pour aluminium » est barrée ; le code 24906210 figure dans la colonne de 32 dents pour le travail du fer.

Les codes de lames de 24 dents de cette page concernent des lignes AS-22A, CT-22, VS-22 ou CT-15. Le document signale ces modèles anciens comme arrêtés. Il ne faut pas déplacer leur code vers la ligne TS-05 ni déduire une compatibilité mécanique de la seule ressemblance du consommable.

## Les brosses ont leurs propres codes

Le constructeur documente des brosses optionnelles pour la TS-05 : 24906211 pour le type normal, 24906212 pour le type dur et 24906213 pour le type double. Les limes figurent dans un autre tableau avec leurs codes.

Le code 24906211 n’est donc pas celui d’une lame TS-05 de 24 dents. Cette distinction est utile lorsqu’une annonce reprend plusieurs numéros de la page sans préciser la nature des accessoires.

## Conserver le périmètre de coupe publié

Le tableau de l’outil donne une épaisseur maximale de tôle en acier doux de 2 mm, une fréquence libre de 10 000 min⁻¹, une longueur globale de 183,5 mm et une masse de 0,54 kg. Cette limite d’acier doux ne doit pas devenir une capacité identique sur tout métal ou tout empilage.

La consommation d’air est indiquée comme moyenne : 0,29 m³/min, soit 290 L/min. La donnée ne suffit pas à certifier un débit continu maximal ni une durée de coupe mesurée sur votre pièce.

## Une commande sans ambiguïté

Faites préciser l’outil complet, la lame incluse, les consommables additionnels et les accessoires optionnels. Pour remplacer une lame, suivez la notice de la TS-05 et les informations de la pièce, avec sa référence exacte.

Le [catalogue d’outils pneumatiques](/outils-pneumatiques/) distingue outils complets et données techniques. Le [guide des régimes de consommation](/guides/consommation-moyenne-en-charge-cle-a-chocs/) aide à préparer la question pneumatique. La valeur ajoutée de cette lecture est de conserver la compatibilité dans le tableau constructeur, plutôt que de créer une lame TS-05 de 24 dents à partir d’une colonne voisine.

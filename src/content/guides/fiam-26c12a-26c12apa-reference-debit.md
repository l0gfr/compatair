Une recherche limitée à « Fiam 26C12 » peut rapprocher des références différentes. 26C12A-2CS, code 114807523, publie 360 L/min ; 26C12APA, code 114814590, publie 420 L/min. Leur vitesse à vide commune de 400 tr/min ne permet pas de fusionner les fiches.

## Le rôle de la référence numérique

Le code de commande relie une ligne technique à un équipement précis. Les suffixes commerciaux peuvent être abrégés dans une annonce ; le code numérique fournit alors un second contrôle utile. Il doit être repris sur le devis et comparé à la documentation reçue.

L’écart calculé entre les consommations est de 60 L/min, soit environ 16,7 % de la valeur de 360 L/min. Ce chiffre exprime un écart de catalogue, pas une différence de productivité ou de consommation annuelle.

## Quand les sources ne présentent pas les mêmes champs

La fiche web de 26C12A-2CS et le tableau de brochure de 26C12APA ne doivent pas se compléter mutuellement par défaut. Une caractéristique présente pour la première n’est pas automatiquement prouvée pour la seconde, même si leurs noms se ressemblent.

Pour 26C12APA, la ligne de brochure utilisée indique 7 L/s, 400 tr/min et 1,05 kg. La pression de référence de 6,3 bar est documentée dans la brochure associée. Les champs absents restent absents au lieu d’être copiés d’une variante voisine.

Le [guide de la coupure automatique](/guides/visseuse-pneumatique-coupure-automatique/) aide à préparer les questions sur le procédé. Pour l’alimentation, choisissez l’outil exact dans le calculateur. Une page de famille ne doit jamais remplacer l’identité de la référence livrée.

La pression de référence est documentée dans [Fiam, brochure technique en-88, page PDF 9](https://www.fiamgroup.com/wp-content/uploads/2019/11/en-88.pdf#page=9), [Fiam, brochure technique en-88, page PDF 14](https://www.fiamgroup.com/wp-content/uploads/2019/11/en-88.pdf#page=14).

# MCP agent-selection benchmark

CompatAir publishes a fixed 50-case benchmark for testing MCP profile and tool selection without treating a simulated fixture as model evidence.

## Files

- `benchmarks/mcp-agent-selection-50.json`: 50 unique prompts and expected calls; 44 are calculable and 6 must preserve a real missing-source-data outcome.
- `scripts/evaluate-mcp-agent-selection.mjs`: evaluates newline-delimited execution traces.
- `/data/mcp-agent-selection-benchmark.json`: public copy generated by Astro.

## Required trace fields

Each NDJSON line must contain:

```json
{
  "case_id": "mcp-001",
  "model": "provider/model-version",
  "client": "client-name-and-version",
  "tokenizer": "tokenizer-name-and-version",
  "manifest_tokens": 3210,
  "selected_profile": "core",
  "selected_tool": "identify_product",
  "arguments": { "reference": "4138540" },
  "result": { "status": "success" }
}
```

`manifest_tokens` must come from the tokenizer used by the target client. Byte count divided by four is not accepted as a production token measurement.

## Acceptance contract

```sh
pnpm benchmark:mcp-agent -- benchmarks/mcp-agent-selection-50.json traces.ndjson report.json
```

The report is eligible only when:

- at least two distinct model-client-tokenizer profiles cover all 50 cases;
- each profile succeeds on at least 80% of calculable tasks;
- missing-data cases remain explicitly `source_data_missing`;
- no `insufficient_data` is attributed to `contract_misunderstood`.

The evaluator validates tool selection, profile selection and required argument subsets. It does not call a model and therefore cannot manufacture multi-model evidence. Real client traces remain a release gate for any public success claim.
